# Tideline Tow

A portrait 3D harbor rescue game built in Godot 4.5.1 Compatibility. Steer a little tug, gather stranded boats into a tow chain, and bring the whole convoy safely home.

Development is in progress. Android is the primary platform; a single-threaded Web edition is also planned. Native advertising uses Google sample IDs; Play Games remains disabled until the owner provides real backend configuration. No app-store release is implied by this repository.
